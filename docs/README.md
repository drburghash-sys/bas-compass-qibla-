# BAS قبلة البر — Offline Web App
مشروع ويب مستقل داخل مجلد docs في مستودع BAS Compass؛ لم تُمس ملفات تطبيق الأندرويد.

## التثبيت
1. GitHub > Settings > Pages > Deploy from a branch > main > /docs > Save.
2. افتح https://drburghash-sys.github.io/bas-compass-qibla-/ عبر Safari على الآيفون أو Chrome على الأندرويد.
3. اختر مشاركة > إضافة للشاشة الرئيسية، وفعّل "فتح كتطبيق ويب".
4. وأنت متصل، افتحه وانتظر رسالة "ملفات التطبيق محفوظة"، وافتحه مجددًا مرة واحدة.
5. اختبره بوضع الطيران. GPS قد يستغرق وقتًا في مكان مكشوف حتى دون شبكة. اطلب إذن الموقع والحركة.

## ملاحظات دقة وسلامة
* حساب القبلة جغرافيًا وفق Great Circle initial bearing إلى الكعبة (21.422487, 39.826206).
* بوصلة iOS WebKit ترجع الشمال المغناطيسي، ويستخدم التطبيق WMM2025 المضمّن لتصحيح الانحراف، صالح للعام 2025 حتى 2029.
* Android DeviceOrientationAbsolute قد يختلف بحسب الجهاز والمتصفح ووضع الشاشة. لذلك تُعرض القراءة على أنها تحتاج للتحقق إذا لم يقدم الجهاز قيمة لدقتها.
* تشويش سيارة/معادن/كهرباء قد يجعل القراءة مضللة. اختبر الجهاز بمقارنة بوصلة موثوقة في مكان مفتوح.
* إذا تعذر GPS، يمكن إدخال إحداثيات يدويًا أو اختيار مركز مدينة تقريبي. حفظ آخر موقع محليًا لا يعني أنه موقعك الحالي.
* التطبيق لا يرسل الإحداثيات إلى أي جهة. لا توجد حسابات أو مزامنة أو خرائط أو خدمات خارجية.
* SW caching requires HTTPS and first installation online. GPS availability in airplane mode is dependent on device and browser.
